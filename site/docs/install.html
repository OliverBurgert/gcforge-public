Installation

Platform-specific instructions for installing GCForge.

System Requirements

  • OS: Windows 10/11 (64-bit), macOS on Apple Silicon (M1 or newer), or 64-bit Linux (Ubuntu 22.04+, Fedora 38+)
  • RAM: 2 GB minimum (4 GB recommended for large collections)
  • Disk: 200 MB for the application + space for your cache database
  • Other: No Python or other dependencies required — everything is bundled

Windows

  1. Download GCForge-windows.zip from GitHub Releases
  2. Right-click the ZIP → Extract All… into a folder of your choice
  3. Open the extracted GCForge folder and run GCForge.exe
  4. Your browser opens to the app automatically once the local server starts

Windows Notes

  • There is no installer yet — GCForge runs straight from the extracted folder. Keep the folder somewhere stable, then right-click GCForge.exe → Send to → Desktop (create shortcut) for easy access.
  • Windows SmartScreen may warn about the unsigned app ("Windows protected your PC"). Click More info → Run anyway to proceed.
  • Your data (database, logs, backups) is stored in %USERPROFILE%\.gcforge\ — the database is %USERPROFILE%\.gcforge\db.sqlite3.
  • To uninstall: delete the extracted GCForge folder, and delete %USERPROFILE%\.gcforge\ to remove your data.

macOS

The macOS build is for Apple Silicon (M1 or newer). It is not yet signed or notarized by Apple, so macOS quarantines it on download — clearing that takes one Terminal command.

  1. Download GCForge-macos.zip from GitHub Releases
  2. Double-click the ZIP in Finder to extract the GCForge folder (e.g. into ~/Downloads)
  3. Open Terminal, clear the quarantine flag, then launch: 
    cd ~/Downloads/GCForge
xattr -dr com.apple.quarantine .
./GCForge
  4. Your browser opens to the app automatically once the local server starts

macOS Notes

  • Why the Terminal step? The app bundles many unsigned libraries. Without clearing quarantine, macOS blocks each one individually (e.g. _struct.cpython-314-darwin.so) and the GUI "Open Anyway" button would need a click per file. xattr -dr clears them all at once — you only need it the first time after downloading.
  • Only Apple Silicon builds are produced right now. Intel Macs are not supported by the current release.
  • Your data (database, logs, backups) is stored in ~/.gcforge/ — the database is ~/.gcforge/db.sqlite3.
  • To uninstall: delete the extracted GCForge folder, and delete ~/.gcforge/ to remove your data.

Linux

  1. Download GCForge-linux.tar.gz from GitHub Releases
  2. Extract it: tar -xzf GCForge-linux.tar.gz
  3. Run it: ./GCForge/GCForge
  4. Your browser opens to the app automatically once the local server starts

Optional: Desktop Integration

To add a desktop entry and menu shortcut (adjust the path to where you extracted the folder):

# Create a desktop entry
mkdir -p ~/.local/share/applications
cat > ~/.local/share/applications/gcforge.desktop <<'EOF'
[Desktop Entry]
Name=GCForge
Comment=Geocache Management Tool
Exec=/path/to/GCForge/GCForge
Icon=utilities-terminal
Type=Application
Categories=Utility;
EOF

# Update icon cache
update-desktop-database ~/.local/share/applications/

Linux Notes

  • GCForge runs from the extracted folder — no installation or root privileges required.
  • Your data (database, logs, backups) is stored in ~/.gcforge/ — the database is ~/.gcforge/db.sqlite3.
  • To uninstall: delete the extracted GCForge folder, and delete ~/.gcforge/ to remove your data.

Building from Source

For developers who want to run GCForge from source: 

# Clone the repository
git clone https://github.com/OliverBurgert/gcforge-public.git
cd gcforge-public

# Install dependencies with uv
uv sync

# Run the development server
uv run python manage.py migrate
uv run python manage.py runserver 127.0.0.1:8000

See the project README for development setup details.
